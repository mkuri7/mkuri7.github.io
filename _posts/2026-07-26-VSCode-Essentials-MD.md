# VS Code Essentials for Markdown writing

## Goal

Markdownを書くために毎日使うVS Code操作を覚える

## 今日覚えるショートカット一覧

| Shortcut | Function |
|----------|----------|
| ⌘ + P | Quick Open |
| ⌘ + Shift + P | Command Palette |
| ⌘ + Shift + V | Markdown Preview |
| ⌘ + Shift + E | Explorer |
| ⌘ + Shift + F | Search |
| ⌘ + ← | 行頭 |
| ⌘ + → | 行末 |
| ⌥ + ← | 前の単語 |
| ⌥ + → | 次の単語 |
| `)` `]` | 閉じ括弧ジャンプ |

## Alfredのワンポイントアドバイス

今回のLessonで一番覚えてほしいのは、`⌘ + P` です。
私もVS Codeでは、Explorerでファイルを探すことはほとんどありません。
「ファイル名の一部を打って開く」という習慣が付くと、プロジェクトが大きくなっても迷子になりません。
